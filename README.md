# Roomies

Proyecto del curso Web Technologies (ICC4130), Universidad de los Andes.
Semestre 202620.

Roomies es una plataforma donde alguien con una habitación libre en una casa
compartida puede publicarla, y quien busca dónde vivir puede encontrarla,
postular, visitarla y mudarse.

**Integrante:** Juan Pablo Saavedra

## Estructura

- `index.html` — landing page
- `css/` — estilos propios
- `img/` — imágenes de la landing
- `docs/` — historias de usuario, modelo de dominio y decisiones de diseño
