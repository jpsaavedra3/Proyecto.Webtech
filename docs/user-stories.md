# Roomies — User Stories

Assignment 1 · Web Technologies (ICC4130) · Universidad de los Andes
Juan Pablo Saavedra

The stories are grouped by role. A member acts as a **host** on the listings of their own
properties and as a **seeker** on everybody else's, so the member section is split in two.

## Visitor (not signed in)

1. As a visitor, I want to browse the published listings without creating an account, so that I can see what Roomies offers before signing up.
2. As a visitor, I want to filter the listings by neighborhood, maximum rent and availability date, so that I only see rooms I could actually take.
3. As a visitor, I want to open a listing and see its photographs, description, rent and the amenities of the property, so that I can judge the room without contacting anybody.
4. As a visitor, I want to read the reviews of a property, so that I can tell whether the place matched what the listing promised.
5. As a visitor, I want to be asked to sign in when I try to apply or save a listing, so that I understand what an account is for.

## Member — as a host

6. As a member, I want to register a property with its address, neighborhood, type, and number of bedrooms and bathrooms, so that my listings have a place to belong to.
7. As a member, I want to choose the amenities my property offers from a catalog, so that seekers can find it when they filter by what they need.
8. As a member, I want to publish a listing for each free room in my property, so that I can rent out more than one room at the same time.
9. As a member, I want to upload photographs of the room and the common areas, so that seekers can see what they would be renting.
10. As a member, I want to write the description and the house rules of a listing, so that I can explain how the house works and who already lives in it.
11. As a member, I want to keep a listing as a draft while I am still writing it, so that nobody sees it before it is ready.
12. As a member, I want to withdraw a listing I no longer want to rent, so that it stops receiving applications.
13. As a member, I want to mark a listing as rented once my new housemate has moved in, so that the listing reflects what actually happened.
14. As a member, I want to see the applications my listings received, so that I can decide who I want to meet.
15. As a member, I want to shortlist an application I am interested in, so that I can arrange a visit with that person.
16. As a member, I want to propose a visit on a shortlisted application with a date and a time, so that the seeker can come and see the room.
17. As a member, I want to cancel a visit and propose another date, so that a change of plans does not end the conversation.
18. As a member, I want to reject an application, so that the seeker is not left waiting for an answer.
19. As a member, I want to accept exactly one applicant for a listing, so that the room is taken and every other applicant gets an answer at the same time.

## Member — as a seeker

20. As a member, I want to apply to a listing with a presentation, the date I want to move in and how long I plan to stay, so that the host knows who I am before we meet.
21. As a member, I want to see the state of every application I have sent, so that I know where I stand without writing to anybody.
22. As a member, I want to confirm a visit the host proposed, so that we both know the appointment is set.
23. As a member, I want to withdraw my application if I am no longer interested, so that the host does not hold the room for me.
24. As a member, I want to review a property after I have visited it, with a rating and a comment, so that other seekers know whether the place matched the listing.
25. As a member, I want to save the listings I like, so that I can compare them later without searching again.
26. As a member, I want to report a listing that looks fraudulent, misleading or offensive, so that a moderator can take it down.
27. As a member, I want my application to be visible only to me and to the host of that listing, so that my message and my contact details stay private.

## Moderator

28. As a moderator, I want to review the reports that members have sent, so that I can decide whether a listing has to be taken down.
29. As a moderator, I want to remove any listing or any review, so that the platform stays usable when somebody breaks the rules.
30. As a moderator, I want to manage the catalogs of neighborhoods and amenities, so that every host describes their property with the same options.
